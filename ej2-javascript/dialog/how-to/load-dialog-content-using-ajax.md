# How to load content via AJAX in ##Platform_Name## Dialog

You can load the Dialog's content dynamically from an external source, such as an external file, using the Syncfusion `Ajax` module from `@syncfusion/ej2-base`. The `Ajax` module makes the request, and the response can be assigned to the Dialog's [content](https://ej2.syncfusion.com/documentation/api/dialog/index-default#content) property inside the Promise `then` handler. Refer to the following demo to see how to load Dialog content using AJAX.

[AJAX Content](https://ej2.syncfusion.com/demos/#/material/dialog/dialog-contents-via-ajax.html)
